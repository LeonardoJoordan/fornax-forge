# Segurança do FORNAX Forge

O aplicativo funciona offline; as verificações de dependências e os downloads
ocorrem no desenvolvimento e na distribuição, não durante o uso do programa.

## Relatar uma vulnerabilidade

Relate privadamente ao mantenedor Leonardo Joordan Belisário Lima da Silva.
No GitHub, use **Security → Advisories → Report a vulnerability**, se essa opção
estiver habilitada no repositório oficial. Sua habilitação é uma pendência do
responsável pelo repositório, não uma capacidade criada por este arquivo.
Se não houver esse canal, abra uma issue apenas solicitando contato privado,
sem publicar detalhes de exploração, assinaturas, senhas ou documentos pessoais.

Informe versão, sistema operacional, passos de reprodução e impacto, usando
um modelo sintético. Não envie material institucional real para reproduzir o erro.

## Suporte

O projeto é mantido por um desenvolvedor individual, sem SLA. As correções serão
priorizadas para a versão estável mais recente; versões antigas não têm garantia
de backport. Não há atualização automática: versões são obtidas nos releases
oficiais do GitHub. Uma vulnerabilidade confirmada deve ser documentada no release
que a corrige, sem expor dados dos usuários ou do relator.

Antes da primeira publicação, habilitar e testar o canal privado acima. As
verificações automatizadas não constituem certificação ou auditoria independente.
