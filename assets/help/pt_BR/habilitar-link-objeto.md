## O que é

Habilitar link associa um objeto a uma coluna de endereço da tabela. O objeto torna-se uma área clicável no PDF quando o registro fornece um endereço.

## Para que serve

Criar convites e materiais digitais com acesso a site, localização, contato ou formulário.

## Como usar

1. Selecione uma caixa de texto, imagem comum ou forma compatível.
2. Em Propriedades → Link, clique em Habilitar link.
3. Informe o Campo da tabela que fornecerá o endereço.
4. Salve, preencha a coluna e gere um PDF para testar o clique.

## Exemplo de uso

Um ícone de localização usa o campo Local_Link para abrir o mapa do evento.

## Dica de uso

Use uma imagem ou texto que indique a ação esperada, como “Confirmar presença”; o endereço fica na tabela, não precisa aparecer no desenho.

## Particularidades e limites

- Na máscara, o link pertence à forma de recorte; a imagem interna não recebe um segundo link concorrente.
- O plano de fundo não oferece esse vínculo.
- Desabilitar link retira a associação; não altera o conteúdo visual do objeto.
