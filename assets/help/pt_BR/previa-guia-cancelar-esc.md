## O que é

A **prévia de guia** é a linha temporária que aparece enquanto você arrasta
a régua para o canvas. A guia definitiva só é adicionada ao concluir o gesto.

## Para que serve

Serve para escolher a posição antes de criar a referência e desistir do gesto
sem deixar uma guia desnecessária no modelo.

## Como usar

1. Pressione a régua superior ou lateral e arraste para o canvas.
2. Observe a linha temporária seguindo o ponto de criação.
3. Para confirmar, solte o botão dentro do canvas.
4. Para desistir antes de concluir, pressione **Esc** durante o arraste.
5. Confira se a prévia desapareceu antes de retomar a edição.

## Exemplo de uso

Você começou a arrastar a régua superior por engano. Pressione Esc para
cancelar o gesto e continuar posicionando os objetos sem criar uma linha extra.

## Dica de uso

Cancelar a criação é diferente de remover uma guia existente. Depois de
soltar e criar a linha, selecione-a e use Delete ou Desfazer.

## Particularidades e limites

- A prévia aparece quando o cursor está dentro do canvas e se esconde ao sair dele.
- Soltar fora do canvas não confirma uma guia.
- Esc cancela esse gesto quando a régua está recebendo a interação.
- A prévia não é um objeto da arte, não entra no arquivo salvo e não é impressa.
- A guia confirmada segue a visibilidade e o bloqueio das guias; a prévia visível
  não garante que a linha definitiva ficará visível se o olho estiver desligado.
- Esc tem outras funções conforme o modo ativo do editor.
