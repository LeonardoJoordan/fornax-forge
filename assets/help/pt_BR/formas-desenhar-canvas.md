## O que é

O menu Formas oferece Quadrado/retângulo, Círculo/elipse e Linha. A opção escolhida inicia um desenho por clique e arrasto no canvas.

## Para que serve

Criar fundos, molduras, separadores e áreas que também podem receber imagens variáveis ou máscaras.

## Como usar

1. Abra Formas e escolha o tipo.
2. Clique no ponto inicial, mantenha o botão esquerdo pressionado e arraste.
3. Solte para criar a forma; selecione-a para ajustar dimensões e estilo em Propriedades.

## Exemplo de uso

Desenhe um retângulo para a foto do cartão, uma elipse para um detalhe e uma linha para separar o título.

## Dica de uso

O nome “Quadrado” não limita o desenho a lados iguais; sem Shift, você pode criar um retângulo livre.

## Particularidades e limites

- Gestos muito pequenos não criam uma forma.
- A linha possui corpo com comprimento e altura; sua espessura visual também pode depender do contorno.
- Criar uma forma não preenche automaticamente os dados de uma imagem variável.
