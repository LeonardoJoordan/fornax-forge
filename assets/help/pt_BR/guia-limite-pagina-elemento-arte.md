## O que é

**Guia**, **limite da página** e **elemento da arte** cumprem funções diferentes.
A guia ajuda a editar; o limite define a área do documento; uma forma, imagem
ou texto participa da composição gerada.

## Para que serve

Serve para escolher a ferramenta certa e evitar esperar que uma referência
de alinhamento apareça como decoração no arquivo final.

## Como usar

1. Para alinhar objetos, crie uma **guia** pela régua ou pelos botões da barra superior.
2. Para definir as dimensões de uma página comum, use o painel **Documento**.
3. Para desenhar uma linha que deve aparecer no resultado, adicione uma **forma Linha**.
4. Para organizar posições do quadro, use a **grade do organograma**.
5. Confira o preview para avaliar a composição sem as referências de edição.

## Exemplo de uso

Um certificado precisa de uma linha visível sob o nome do responsável.
Use uma forma Linha para esse traço. Uma guia pode ajudar a posicioná-lo,
mas não substitui a linha que será gerada.

## Dica de uso

Objetos alinhados a uma guia não ficam ligados a ela. Mover ou excluir a guia
não leva os objetos junto; ela apenas ofereceu uma referência durante a edição.

## Particularidades e limites

- Réguas, guias, grade e molduras de seleção não são conteúdo da arte gerada.
- O limite da página não é um contorno decorativo. Para um traço visível,
  use os recursos de forma ou contorno apropriados.
- Conteúdo fora de uma página comum pode aparecer atenuado no editor, mas
  não amplia automaticamente a área do arquivo final.
- No organograma, os limites do quadro acompanham a composição e a margem configurada.
- Ocultar ou bloquear guias não altera o tamanho do documento.
- Margens e marcas de corte da geração têm configurações próprias; uma guia
  não cria esses recursos de saída.
