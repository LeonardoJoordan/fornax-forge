## O que é

**Camadas** lista os objetos da página ativa: textos, imagens, formas e assinaturas, além das referências especiais de fundo e Organograma. A lista permite identificar elementos sobrepostos e escolher um ou vários integrantes.

## Para que serve

Use a lista para selecionar o objeto certo quando ele está atrás de outro ou quando você quer editar apenas parte de um grupo.

## Como usar

1. Abra Camadas, no painel esquerdo.
2. Clique no nome do objeto desejado.
3. Use Ctrl + clique para linhas separadas ou Shift + clique para um intervalo.
4. Confira os destaques no canvas e os controles disponíveis à direita.

## Exemplo de uso

Um logotipo encobre uma linha decorativa. Escolha a linha por Camadas para ajustar sua aparência sem mover o logotipo.

## Dica de uso

A seleção pela lista pode escolher integrantes específicos de um grupo, enquanto um clique no canvas pode expandir a seleção para o grupo inteiro.

## Particularidades e limites

- Guias e conectores não são linhas comuns dessa lista.
- Objetos bloqueados ou ocultos têm restrições de edição; confira olho e cadeado.
- A linha Organograma representa a composição inteira; a árvore da estrutura organiza os blocos.
