## O que é

**Desagrupar** retira a associação de grupo entre objetos. Os integrantes
permanecem na composição e voltam a poder ser selecionados individualmente
no canvas.

## Para que serve

Serve para reorganizar uma composição, ajustar seus integrantes ou substituir
um elemento sem manter a seleção automática de todo o grupo.

## Como usar

1. Selecione o grupo ou um de seus integrantes.
2. Pressione **Ctrl+Shift+G** ou use o controle contextual **Desagrupar** junto
   de Camadas, quando ele apresentar essa ação.
3. Clique no espaço vazio para limpar a seleção que ficou ativa.
4. Selecione o objeto individual que deseja editar.
5. Se necessário, agrupe novamente os elementos depois dos ajustes.

## Exemplo de uso

Um título e uma linha decorativa estão agrupados. Desagrupe para trocar
apenas a linha de posição e, depois de revisar o resultado, reúna-os novamente.

## Dica de uso

Desagrupar não espalha nem reposiciona os objetos. Se vários continuarem
selecionados logo após a ação, isso é a seleção temporária dos antigos integrantes.

## Particularidades e limites

- A ação desfaz os grupos relacionados aos objetos selecionados, incluindo
  seus outros integrantes, mesmo que apenas um deles tenha sido escolhido pela lista.
- Textos, imagens, tamanhos e posições permanecem como estavam.
- Uma máscara não é removida por Desagrupar; seu vínculo de recorte é separado
  do agrupamento comum.
- Um conjunto de cartões do organograma não é um grupo gráfico desse tipo.
  Para mudar linhas e colunas, use a edição do bloco.
- Se não houver objetos agrupados na seleção, o atalho não tem grupo para desfazer.
- Desfazer pode restaurar um agrupamento recém-removido.
