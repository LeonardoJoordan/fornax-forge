## O que é

Raio de curva define o arredondamento das mudanças de direção do conector, em milímetros. Zero mantém as quinas retas.

## Para que serve

Suavizar as ligações sem trocar a estrutura de subordinação.

## Como usar

1. Selecione um ou mais conectores.
2. Em Propriedades → Conectores, informe o Raio de curva.
3. Use 0 para quinas retas ou um valor maior para curvas.
4. Confira os trechos próximos aos cartões e ajuste o espaço se necessário.

## Exemplo de uso

Use um raio de 3 mm para suavizar as mudanças de direção de um quadro com cartões pequenos.

## Dica de uso

Aumentar muito o valor pede o maior arredondamento possível, mas não garante que todas as quinas usem exatamente esse raio.

## Particularidades e limites

- O raio efetivo é limitado pelos comprimentos dos trechos vizinhos e pelos obstáculos.
- Uma curva pode ser reduzida ou permanecer reta quando não houver espaço seguro.
- O conector continua seguindo um caminho calculado; o recurso não oferece alças para desenhar manualmente uma curva livre.
