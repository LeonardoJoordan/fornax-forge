## O que é

**Usar modelo** é o botão que confirma a escolha na galeria de pontos de
partida e abre o editor com a opção selecionada.

## Para que serve

Ele encerra a etapa de escolha e inicia a criação: com uma composição pronta
para personalizar ou com uma página em branco.

## Como usar

1. Na tela principal, abra **Arquivo → Novo modelo**.
2. Selecione uma miniatura. Confira o destaque, o nome e a descrição para
   saber qual opção será aberta.
3. Clique em **Usar modelo**.
4. Personalize a composição no editor e use **Salvar modelo** para guardá-la.

Um **duplo clique na miniatura** tem o mesmo efeito de confirmar a escolha.

## Exemplo de uso

Para preparar cartões de aniversário, selecione o exemplo correspondente e
clique em **Usar modelo**. O editor abre com os elementos desse cartão, e
você pode adaptar a identidade visual antes de salvar sua versão.

## Dica de uso

Confira a seleção antes de confirmar. A galeria começa com **Começar em
branco** selecionado; clicar em Usar modelo sem trocar essa seleção abre
uma página em branco.

## Particularidades e limites

- Confirmar a escolha **não salva** o novo modelo. A gravação é feita pelo
  comando Salvar modelo no editor.
- A composição pronta abre como uma cópia independente do exemplo distribuído.
- Na galeria de **Adicionar organograma**, o botão se chama **Usar estrutura**.
  Ele adiciona a estrutura escolhida ao documento atual, usando a Página 1
  como cartão.
- Se uma opção não puder ser carregada, a galeria apresenta um aviso.
  Confira a mensagem antes de continuar.
