## O que é

**Copiar objetos**, com Ctrl+C, guarda os elementos selecionados na memória
interna do editor para colá-los depois. Os objetos de origem permanecem no modelo.

## Para que serve

Serve para reaproveitar partes de uma composição na mesma página ou em outra
página do modelo, preservando suas características sem recriá-las.

## Como usar

1. Encerre a edição de texto, se estiver digitando dentro de uma caixa.
2. Selecione os objetos desejados no canvas ou pela lista Camadas.
3. Pressione **Ctrl+C**.
4. Vá ao local de destino e use **Ctrl+V**.
5. Confira os objetos colados e ajuste sua posição.

## Exemplo de uso

Você criou um título com uma linha decorativa para um certificado.
Copie os dois objetos e cole na segunda página para reaproveitar o cabeçalho.

## Dica de uso

Copie todos os componentes necessários de uma só vez. Em máscaras, a cópia
leva a estrutura associada de forma e imagens, para manter o recorte.

## Particularidades e limites

- Essa cópia usa a memória interna do editor; não gera um arquivo nem coloca
  uma imagem da composição na área de transferência do sistema.
- Copiar não retira nem desloca os objetos de origem.
- A cópia de objetos comuns conserva sua ordem relativa de sobreposição.
- O plano de fundo do documento não é copiado como um objeto comum.
- Ao copiar blocos do organograma, são preservadas as conexões entre os blocos
  incluídos na seleção. Conexões com blocos não copiados ficam de fora.
- Se houver blocos selecionados junto de objetos comuns, a operação de cópia
  dos blocos tem prioridade; faça as cópias separadamente.
- Durante a digitação, Ctrl+C copia o texto selecionado, conforme o foco.
