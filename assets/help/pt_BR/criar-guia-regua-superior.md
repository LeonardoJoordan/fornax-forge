## O que é

Arrastar a **régua superior** para o canvas cria uma guia horizontal.
A linha serve como referência de altura para organizar a composição.

## Para que serve

Serve para alinhar objetos em uma mesma faixa, como a base de logotipos,
o topo de títulos ou a linha de um rodapé.

## Como usar

1. Na régua acima do canvas, pressione o botão esquerdo.
2. Mantenha o botão pressionado e arraste para dentro da área de desenho.
3. Observe a prévia horizontal e escolha a altura desejada.
4. Solte dentro do canvas para criar a guia.
5. Para ajustar com precisão depois, selecione a guia e altere **Y**.

## Exemplo de uso

Em um certificado, crie uma guia horizontal na altura planejada para a
base dos logotipos. Use essa referência para posicionar os elementos do cabeçalho.

## Dica de uso

A guia nasce na posição em que você solta o arraste. Para começar no centro
do documento, o botão Adicionar guia horizontal oferece um caminho direto.

## Particularidades e limites

- Pressione Esc durante a criação para cancelar a prévia antes de soltar.
- Soltar fora do canvas não cria uma guia.
- A criação respeita o estado de visibilidade e bloqueio das guias.
  Se a linha não aparecer ou não puder ser movida, confira esses controles.
- Uma guia horizontal se move verticalmente; sua coordenada útil é Y.
- Guias não aparecem no preview da arte nem no arquivo gerado.
- Para uma guia vertical, arraste a régua lateral.
