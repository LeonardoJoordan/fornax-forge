## O que é

**Tabela → CÉLULAS** permite escolher a cor e a opacidade do preenchimento das células selecionadas.

## Para que serve

Destacar títulos, diferenciar cabeçalhos e criar linhas alternadas sem colocar retângulos separados atrás do texto.

## Como usar

1. Selecione as células desejadas.
2. Clique no seletor de cor ou informe uma cor hexadecimal no formato **#RRGGBB**.
3. Ajuste a opacidade do preenchimento: 100% é opaco, 0% deixa o fundo transparente.
4. Para alterar texto ou contornos, use os controles próprios dessas propriedades.

## Exemplo de uso

Pinte a primeira linha do boletim de azul escuro e use texto branco; no corpo, mantenha fundos claros para leitura.

## Dica de uso

Selecione uma linha por vez para criar faixas alternadas. A tabela não aplica automaticamente um padrão de zebra.

## Particularidades e limites

- Preenchimento, texto e contornos têm controles independentes.
- Tornar o preenchimento transparente não oculta o texto nem os traços.
- **Vários** indica que a seleção possui cores ou opacidades diferentes.
- A opacidade geral em Propriedades afeta o objeto inteiro, incluindo texto e contornos.
