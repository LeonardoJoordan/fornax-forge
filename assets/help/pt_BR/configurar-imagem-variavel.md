## O que é

Imagem variável associa uma forma a um campo da tabela. Cada registro informa qual foto será carregada da pasta escolhida na tela principal.

## Para que serve

Gerar cartões com fotos diferentes usando a mesma área e o mesmo modelo.

## Como usar

1. Crie e selecione um retângulo ou uma elipse.
2. Em Propriedades → Imagem variável, clique em Usar imagem variável.
3. Informe um nome no Campo da tabela, como Foto.
4. Salve e escolha a pasta das fotos na tela principal; preencha a coluna correspondente.

## Exemplo de uso

Um cartão usa `{nome}` para o texto e o campo Foto para a imagem de cada funcionário.

## Dica de uso

Use um identificador estável no nome dos arquivos, como matrícula, para facilitar a correspondência com a planilha.

## Particularidades e limites

- Linhas e plano de fundo não recebem imagem variável.
- Uma forma com máscara de imagens fixas não habilita simultaneamente este recurso.
- Desabilitar remove a associação do campo à forma; não transforma as fotos externas em imagens fixas.
