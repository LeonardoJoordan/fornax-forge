## O que é

**Seleção múltipla**, **grupo de objetos** e **conjunto de cartões** reúnem
elementos de maneiras diferentes. Escolher o recurso adequado evita confundir
edição da arte com organização dos dados do quadro.

## Para que serve

Serve para decidir como trabalhar: selecionar temporariamente para uma operação,
agrupar uma composição para reutilizar sua organização ou criar um bloco do organograma.

## Como usar

1. Para uma operação pontual em vários objetos, faça uma **seleção múltipla**.
2. Para manter textos, imagens e formas associados nas próximas edições, use **Agrupar**.
3. Para distribuir pessoas em cartões repetidos, adicione um **bloco** na aba Organograma.
4. Edite a aparência do cartão na página 1 e a disposição do conjunto na edição do bloco.
5. Confira o tipo selecionado antes de usar as propriedades disponíveis.

## Exemplo de uso

Para deslocar três caixas uma única vez, basta selecioná-las juntas.
Para conservar um cabeçalho organizado, agrupe seus objetos.
Para mostrar vinte alunos em uma grade, crie um bloco com linhas e colunas no organograma.

## Dica de uso

O conjunto do organograma reutiliza o cartão da página 1. Ele evita desenhar
vinte cartões manualmente e mantém um destino definido para os dados da tabela.

## Particularidades e limites

- A seleção múltipla termina quando você troca ou limpa a seleção.
- O grupo gráfico é uma associação salva entre objetos; não cria linhas de dados
  nem uma relação de superior e subordinado.
- O bloco pode representar um cartão ou uma grade de cartões, com nome, capacidade
  e conexões próprios. Não é desfeito pelo atalho Desagrupar.
- Os cartões repetidos usam o mesmo desenho da página 1; seus dados variam conforme
  o preenchimento destinado ao bloco.
- Conexões entre blocos representam a hierarquia do quadro e são editadas
  pelas ferramentas específicas do organograma.
