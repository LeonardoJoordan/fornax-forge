## O que é

Imagens ligadas a uma máscara aparecem associadas à forma, com indicação de vínculo. O indicador **Máscara** reúne forma e imagens; a ordem das imagens vinculadas controla sua sobreposição dentro do recorte.

## Para que serve

Serve para encontrar a imagem certa, enquadrá-la e organizar várias imagens que compartilham uma forma.

## Como usar

1. Localize a forma e as imagens vinculadas em Camadas.
2. Passe o mouse no indicador para confirmar que se trata de Máscara.
3. Clique no indicador para selecionar sua estrutura.
4. Para ajustar a sobreposição interna, reordene as linhas das imagens vinculadas e confira o recorte.
5. Use Editar máscara para alterar o enquadramento da imagem desejada.

## Exemplo de uso

Duas imagens compartilham uma forma retangular. Leve a imagem que deve ficar visível para a posição superior entre as vinculadas.

## Dica de uso

No canvas, a seleção técnica da máscara usa sua forma para evitar deslocar a imagem duas vezes. A lista pode destacar também os integrantes associados.

## Particularidades e limites

- Reordenar não remove o vínculo de máscara.
- O recorte depende da forma, inclusive de seus cantos.
- O indicador de máscara é diferente do grupo gráfico comum.
- Para liberar uma imagem, use Remover máscara; para só ajustar seu recorte, use o enquadramento.
