## O que é

**Camadas** é a lista de elementos no painel esquerdo, abaixo das ferramentas
de adição. Ela mostra os objetos da página ativa e oferece controles de
visibilidade, bloqueio e organização.

## Para que serve

Use a lista para localizar objetos difíceis de alcançar no canvas, organizar
sobreposições e proteger elementos que já estão posicionados corretamente.

## Como usar

1. Localize o elemento pelo nome na lista **Camadas** e clique para selecioná-lo.
2. Use o **olho** para exibir ou ocultar a camada e o **cadeado** para bloquear
   ou desbloquear sua edição.
3. Arraste uma camada para alterar sua posição na ordem visual, respeitando
   as restrições dos elementos especiais.
4. Use os botões junto ao título Camadas para **Renomear**, **Duplicar**,
   **Agrupar** ou **Excluir** uma seleção compatível.

## Exemplo de uso

Uma imagem de fundo encobre o texto de um convite. Pela lista, coloque a
imagem abaixo do texto. Depois, bloqueie a imagem para evitar movê-la enquanto
ajusta os nomes e a mensagem.

## Dica de uso

Use nomes ligados à função de cada objeto. Uma composição com **“Fundo”**,
**“Logo”** e **“Nome”** é mais fácil de organizar do que uma lista com vários
elementos de nomes parecidos.

## Particularidades e limites

- Camadas mais acima na lista aparecem à frente das que estão abaixo.
- **Ocultar** uma camada afeta o editor e o arquivo final. **Bloquear**
  restringe a edição e mantém o elemento visível.
- O plano de fundo do documento tem restrições próprias de movimentação,
  duplicação e exclusão.
- Na aba Organograma, a camada **Organograma** representa os cartões e
  conectores em relação à arte adicional. Ela não substitui a hierarquia
  de subordinação, organizada em Estrutura do quadro.
