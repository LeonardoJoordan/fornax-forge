## O que é

A **seleção múltipla** reúne vários elementos para operações conjuntas.
Os modificadores de teclado ajudam a acrescentar ou retirar itens sem
substituir a seleção a cada clique.

## Para que serve

Use-a para mover elementos juntos, preparar um agrupamento ou aplicar
operações compatíveis a vários objetos de uma vez.

## Como usar

1. No canvas, clique no primeiro objeto.
2. Segure **Ctrl** e clique nos outros objetos para acrescentá-los à seleção.
3. Use Ctrl + clique em um objeto selecionado para alternar sua participação,
   considerando o comportamento dos grupos.
4. Na lista Camadas, Ctrl + clique escolhe linhas separadas. Para um intervalo,
   clique na primeira linha e use **Shift + clique** na última.
5. Confira os destaques antes de mover ou transformar a seleção.

## Exemplo de uso

Para deslocar um título e duas linhas decorativas, selecione os três
elementos com Ctrl + clique e mova-os juntos. A distância entre eles
é preservada no deslocamento.

## Dica de uso

Seleção múltipla é temporária. Se você precisa manter os elementos unidos
nas próximas edições, considere **Agrupar** depois de organizar a composição.

## Particularidades e limites

- Shift + clique para escolher um intervalo refere-se à lista Camadas.
  No canvas, use Ctrl para selecionar objetos separados.
- Os controles disponíveis mudam na seleção múltipla. A edição tipográfica
  de uma caixa individual não funciona da mesma forma nesse contexto.
- Grupos existentes podem expandir a seleção para seus integrantes ao clicar
  no canvas. Pela lista, você pode escolher integrantes específicos.
- Guias não permanecem na mesma seleção de objetos comuns.
- No organograma, a seleção de vários conectores permite editar sua aparência
  em conjunto, sem transformá-los em um grupo de objetos da arte.
