## O que é

Fora do enquadramento, mover ou transformar a forma move o conjunto de máscara e imagens. Remover máscara libera as imagens como objetos comuns.

## Para que serve

Reposicionar uma composição já enquadrada, duplicá-la ou voltar a trabalhar com a imagem inteira.

## Como usar

1. Selecione a forma para mover, redimensionar, copiar ou duplicar a máscara completa.
2. Para liberar uma imagem específica, selecione sua entrada vinculada e use Remover máscara.
3. Para liberar todas as imagens da forma, selecione a forma e use Remover máscara.
4. Confira a ordem das camadas após a liberação.

## Exemplo de uso

Duplique uma foto emoldurada para criar outra área de composição; remova a máscara quando quiser reaproveitar a imagem sem recorte.

## Dica de uso

Diferencie reenquadrar a imagem de redimensionar o conjunto: o primeiro muda a foto dentro da moldura; o segundo altera a composição.

## Particularidades e limites

- Remover máscara não apaga o arquivo nem elimina a forma.
- A ordem e a posição da composição são preservadas tanto quanto possível, mas a imagem liberada volta a aparecer fora do recorte.
- Copiar uma máscara inclui suas imagens vinculadas, evitando um recorte vazio.
