## O que é

**Limpar a seleção** remove o destaque dos objetos que estavam selecionados.
No modo normal de edição, um clique em uma região vazia do canvas faz isso.

## Para que serve

Use essa ação para examinar a composição sem alças de seleção ou para
encerrar a escolha atual antes de selecionar outros elementos.

## Como usar

1. Solte os botões de arraste e a tecla Espaço, caso estejam ativos.
2. Clique uma vez em um espaço vazio do canvas, sem Ctrl.
3. Confira se os objetos deixaram de aparecer selecionados.
4. Para retomar a edição, selecione o elemento desejado novamente.

## Exemplo de uso

Depois de redimensionar o logotipo de um convite, clique fora dos objetos
para avaliar sua aparência sem as alças. O logotipo continua na posição
e no tamanho ajustados.

## Dica de uso

Se uma imagem ocupa a página inteira, a região que parece vazia pode fazer
parte dessa imagem. Clique na área externa à página para encontrar um
espaço realmente livre de objetos selecionáveis.

## Particularidades e limites

- Limpar a seleção não exclui objetos nem desfaz alterações.
- Um clique com Ctrl pode conservar a seleção; para limpá-la, clique sem
  esse modificador.
- A seleção vazia deixa controles específicos indisponíveis, pois não há
  objeto definido para receber o ajuste.
- Durante a edição de texto, mudar a seleção encerra a edição e preserva
  o conteúdo. Esc também pode ser usado para sair da digitação.
- Em modos como desenho de forma ou escolha de superior, o clique tem outra
  função. Encerre esse modo antes de limpar a seleção pelo espaço vazio.
