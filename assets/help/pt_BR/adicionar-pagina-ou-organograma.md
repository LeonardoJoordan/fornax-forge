## O que é

O botão + abre as opções Adicionar página e Adicionar organograma. O modelo pode ter duas páginas comuns ou uma Página 1 com organograma.

## Para que serve

Escolher entre um documento com frente e verso e um quadro que replica o cartão da primeira página.

## Como usar

1. Clique em + no seletor de páginas do editor.
2. Escolha Adicionar página para criar a segunda página em branco.
3. Escolha Adicionar organograma para abrir o painel de estruturas.
4. Se a outra modalidade já existir, remova-a antes de trocar de modalidade.

## Exemplo de uso

Para um crachá com verso, adicione uma página. Para um quadro de pessoal, use o cartão da Página 1 e adicione um organograma.

## Dica de uso

Decida o tipo de modelo antes de preparar muito conteúdo na segunda área; as modalidades são exclusivas.

## Particularidades e limites

- O botão usa um menu mesmo sem uma seta desenhada ao lado.
- O documento não cria uma terceira página comum.
- Uma segunda página impede adicionar organograma, e um organograma impede adicionar outra página comum.
