## O que é

Arrastar a **régua lateral** para dentro do canvas cria uma guia vertical.
Ela oferece uma referência de coluna para os objetos da composição.

## Para que serve

Serve para alinhar laterais ou centros de textos, imagens e formas em uma
mesma posição horizontal.

## Como usar

1. Pressione o botão esquerdo sobre a régua à esquerda do canvas.
2. Arraste para dentro da área de desenho mantendo o botão pressionado.
3. Observe a prévia vertical e escolha a posição da coluna.
4. Solte dentro do canvas para criar a guia.
5. Se precisar de uma posição exata, selecione a guia e ajuste **X**.

## Exemplo de uso

Um cartão tem fotografia, nome e função organizados em uma coluna.
Crie uma guia vertical para ajudar a manter seus centros alinhados.

## Dica de uso

Use duas guias verticais para planejar os limites de uma faixa de texto.
Elas ajudam a comparar a largura disponível sem adicionar linhas à arte.

## Particularidades e limites

- Esc cancela a criação ainda em andamento.
- Soltar fora do canvas não adiciona a guia.
- Guias novas seguem os controles atuais de visibilidade e bloqueio.
- Uma guia vertical se move horizontalmente; seu campo de posição é X.
- A guia é uma referência do editor, não uma linha impressa.
- O organograma usa a grade para mover seus elementos livres; uma guia ali
  não substitui o magnetismo da grade.
