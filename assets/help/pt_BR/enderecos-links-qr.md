## O que é

Os endereços de link vêm da tabela. O programa conserva prefixos como `https://`, `http://`, `mailto:` e `tel:`; endereços sem um desses prefixos recebem `https://`. Uma imagem de QR code é um recurso visual diferente.

## Para que serve

Preparar destinos digitais e distinguir clique no PDF de leitura por câmera.

## Como usar

1. Para um site ou mapa, informe a URL completa com `https://`.
2. Para e-mail, use `mailto:events@fornaxcorporation.com`; para telefone, use `tel:` seguido do número.
3. Teste o endereço no PDF.
4. Se desejar acesso também no papel, importe uma imagem de QR code preparada com o mesmo destino e teste sua leitura.

## Exemplo de uso

No convite, um ícone clicável abre a confirmação no PDF e um QR code impresso permite acessar o mesmo formulário pelo celular.

## Dica de uso

Prefira endereços completos para evitar que um prefixo automático transforme um texto incorreto em outro endereço.

## Particularidades e limites

- A normalização não comprova que o site existe ou que o destino está correto.
- Esquemas diferentes dos suportados não devem ser usados como se fossem validados.
- Importar um QR code não gera o código nem lê seu conteúdo; a ferramenta importa a imagem.
