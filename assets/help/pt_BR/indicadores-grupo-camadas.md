## O que é

Os **indicadores de grupo**, com número junto aos nomes das camadas, identificam objetos associados. Clicar no indicador seleciona o grupo; arrastá-lo permite reordenar as linhas selecionadas como um bloco.

## Para que serve

Serve para selecionar e mudar a profundidade de uma composição sem separar seus integrantes na ordem visual.

## Como usar

1. Encontre um indicador com a dica Grupo na lista Camadas.
2. Clique para selecionar os integrantes compatíveis.
3. Para reordenar, arraste pelo indicador até uma linha de destino fora da seleção.
4. Confira a indicação e a ordem resultante antes de continuar.

## Exemplo de uso

Um cabeçalho agrupado contém símbolo e legenda. Use seu indicador para levar a composição acima de uma imagem decorativa.

## Dica de uso

O número identifica o grupo, não o nome ou o posto de um bloco do organograma. Passe o mouse para distinguir Grupo de Máscara.

## Particularidades e limites

- O arraste conserva a ordem relativa das linhas selecionadas.
- Uma linha pertencente à própria seleção não é um destino útil de reordenação.
- O gesto altera a profundidade visual, não a posição na página.
- Objetos bloqueados podem não participar da seleção no canvas.
