## O que é

Enter cria um novo parágrafo; Shift+Enter cria uma quebra de linha dentro do parágrafo. A quebra automática ocorre quando o texto alcança a largura da caixa.

## Para que serve

Organizar títulos, endereços e textos longos, preservando espaço para os dados reais.

## Como usar

1. Entre na edição e use Enter para separar parágrafos ou Shift+Enter para continuar em outra linha.
2. Ajuste a largura da caixa para controlar as quebras automáticas.
3. Ajuste altura, fonte e entrelinha e confira a prévia com dados de diferentes tamanhos.

## Exemplo de uso

Reserve altura para um nome composto de duas linhas em um crachá, mesmo que o placeholder `{nome}` ocupe apenas uma.

## Dica de uso

Teste o maior conteúdo esperado; o desenho com placeholders curtos não garante que todos os registros vão caber.

## Particularidades e limites

- O programa não reduz automaticamente a fonte para encaixar todo nome.
- Alterar a largura pode mudar as quebras sem alterar o texto digitado.
- Quebras explícitas permanecem após a substituição dos campos.
