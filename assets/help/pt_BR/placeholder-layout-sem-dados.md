## O que é

Sem um registro para preencher, o desenho do modelo pode mostrar os próprios marcadores, como `{nome}`. Essa representação permite reconhecer a composição antes de inserir dados.

## Para que serve

Conferir o layout e os locais reservados às informações variáveis.

## Como usar

1. Abra o modelo e observe a prévia sem dados.
2. Localize as caixas e os marcadores.
3. Insira dados representativos na tabela e confira a versão preenchida.

## Exemplo de uso

Veja o quadro de organograma vazio para conferir a distribuição dos cartões; depois use nomes reais para validar as quebras.

## Dica de uso

Use tanto a visualização do layout quanto a preenchida: elas respondem a verificações diferentes de composição e de conteúdo.

## Particularidades e limites

- O marcador não representa o comprimento máximo dos dados.
- Ao existir uma linha de dados, as regras de campos vazios e de exibição de blocos passam a valer.
- O layout não inventa nomes, funções ou fotos para completar registros ausentes.
