## O que é

Pressionar e arrastar com o **botão do meio do mouse** desloca a visualização
do canvas. Em muitos mouses, esse botão é acionado pressionando a própria roda.

## Para que serve

Esse comando oferece uma alternativa à mãozinha com Espaço para percorrer
a composição, especialmente enquanto você trabalha com o zoom ampliado.

## Como usar

1. Posicione o cursor sobre a área de desenho.
2. Pressione e mantenha o botão do meio.
3. Arraste o mouse para deslocar a visualização. O cursor indica a navegação
   com uma mão fechada.
4. Solte o botão para encerrar o deslocamento.

## Exemplo de uso

Ao conferir um organograma grande, pressione a roda e arraste para passar
da direção para os conjuntos de equipes. A organização dos blocos permanece
igual; apenas a região visível muda.

## Dica de uso

Use essa navegação entre ajustes de um objeto: você pode deslocar a
visualização sem precisar arrastar o objeto selecionado. Para aproximar
um detalhe, combine o comando com **Ctrl + roda**.

## Particularidades e limites

- O mouse precisa oferecer um botão do meio reconhecido pelo sistema.
  Girar a roda não equivale a pressioná-la como botão.
- Em um touchpad sem esse botão, use a mãozinha com **Espaço** ou as barras
  de rolagem do canvas.
- O gesto vale sobre o canvas; outros controles podem tratar esse botão
  de outra forma.
- Soltar o botão encerra a navegação. Se a interação ficar ativa por engano,
  use **Esc** para encerrá-la.
- O comando não altera o tamanho físico do documento nem as posições
  salvas dos elementos.
