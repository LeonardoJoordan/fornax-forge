## O que é

A ferramenta Texto insere uma caixa editável no canvas, inicialmente com `{campo}`. A caixa tem posição e dimensões próprias.

## Para que serve

Criar títulos, instruções e campos que serão preenchidos com os dados de cada registro.

## Como usar

1. Clique em Texto na barra de ferramentas.
2. Posicione a caixa e ajuste suas dimensões em Propriedades.
3. Dê duplo clique no conteúdo para escrever; use o painel Texto para formatar.

## Exemplo de uso

Em um crachá, crie uma caixa para `{nome}` e outra para o título fixo da instituição.

## Dica de uso

Separe informações com funções diferentes em caixas distintas: isso facilita alinhar nome, cargo e legenda.

## Particularidades e limites

- O texto inicial é um placeholder; substitua-o se precisar de texto fixo.
- A largura da caixa controla a quebra de linha; redimensioná-la isoladamente não aumenta automaticamente a fonte.
